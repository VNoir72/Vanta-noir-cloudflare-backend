# Catalogue administration QA — 20 September 2026

Added 41 preset colour swatches and persisted custom colours/categories via authenticated endpoints and existing D1 store_meta records. New colourways add missing S–XXL rows (or One size for existing one-size products), with stock zero. Existing variant rows remain unchanged. Category names selected in Product Studio are used by public catalogue filtering; saved categories appear under their department when published products use them.

Browser QA used the local supervised preview, with iframe viewports at 360, 390, 430, 768, 820, 1024, 1180, 1366, 1440 and 1920 CSS pixels, height 900. Storefront, product detail, empty checkout, dashboard and open product-editor fixture passed document horizontal-overflow checks. The editor also passed dialog scroll-width checks. Desktop scrollbar consumes 15 px of each viewport. Visually inspected mobile dashboard, tablet dashboard, desktop dashboard and mobile editor. This is representative Chromium viewport coverage, not testing on physical iPhones/iPads or Safari, and not a claim to cover every device. Admin UI was rendered from the actual component with sample data and writes disabled; production login was not bypassed. Database write/auth tests ran separately in isolated Miniflare.

TypeScript and integration tests cover persisted colours/categories, public CORS, rejected unauthenticated writes, checkout, inventory reservations, payment idempotency and catalogue edits. Measurement references are not automatically applied to products. They remain provisional until approved against actual samples. Eight published reference charts cover windbreaker jackets, training jackets, performance jerseys (men/women), mesh tanks, sports hoodies (unisex/women) and short sports shorts. The unisex hoodie chart uses explicitly labelled calculated midpoints of source ranges. Missing measurements remain blank. Other garment types require pattern-specific research and physical samples; no unsupported final specifications were invented.

Sources: https://www.lookfly.com/pages/sizing and https://www.lookfly.com/pages/windbreaker-sizing . The dedicated windbreaker page was preferred because its metric measurements are consistent; the general page has an apparent units mismatch for windbreakers. Sleeve values were omitted where measurement origin was not verified.
