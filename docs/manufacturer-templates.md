# Manufacturer information: where to enter it

Open Products → edit → Fit, materials & product information.

The manufacturer template selects an accessory type from the product name. You can select another template without erasing saved notes. Blank inputs are examples of what to request, not specifications. Completed entries update Saved sizing & fit notes and are saved with the product's normal Save changes action. Customers see those notes under Sizing & fit. The template does not change prices, stock, size variations or publication status.

| Manufacturer supplies | Admin field |
| --- | --- |
| Exact product type | Garment type |
| Fit, adjustment and supported size range | Fit description |
| Fibre percentages, lining composition | Fabric composition |
| Fabric GSM where relevant | Fabric weight |
| Closures, seams, cushioning, embroidery | Construction and technical features |
| Approved wash/dry/iron instructions | Care instructions |
| Number of items or pairs included | What is included in the purchase |
| Packed parcel weight measured on a scale | Packed weight (grams) |
| Socks: shoe-size system/range, flat foot length, heel-to-cuff height, relaxed cuff width | Manufacturer measurements → Socks |
| Caps: full head circumference range, crown height, peak length, adjustment | Manufacturer measurements → Caps / hats / beanies |
| Boxers: size, flat relaxed/stretched waist, hip, inseam and outer length | Bottom chart for multiple sizes; underwear template for extra notes |
| Bags: height, width, depth, strap range and confirmed capacity | Manufacturer measurements → Bags / backpacks |
| Belts: wearable waist range, width, total length and buckle dimensions | Manufacturer measurements → Belts |
| Gloves: hand size range, glove length and fit | Manufacturer measurements → Gloves |
| Scarves: width, length and separate fringe length | Manufacturer measurements → Scarves |
| Sunglasses: lens, bridge, temple and frame dimensions in mm | Manufacturer measurements → Sunglasses |

Use manufacturer-confirmed size labels in Colours, designs & stock. Do not change Size pending to One size without confirmation. Head and hand circumferences are full measurements; garment waist/chest/hip widths are measured across one side. Do not enter dimensions from another product or infer fabric, UV protection or wash temperatures from a picture.

Unknown entries stay blank. For multiple accessory sizes, identify each size explicitly in Saved sizing & fit notes. These free-text notes do not automatically convert cm to inches; units stay written beside every measurement. Existing garment charts and approvals remain unchanged.
