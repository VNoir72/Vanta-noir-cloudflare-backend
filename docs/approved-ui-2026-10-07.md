# Approved slim search and staff portal

Implements the owner's approved slimmer preview and staff-portal comparison.

- Shared customer header: 28px visible search outline, readable 16px input, same-row logo/search/saved/bag. Search replaces desktop links sideways and does not move the hero. The same header is used on product, information, checkout and policy pages. Scroll down hides it; scroll up, focus and open search restore it. Escape and close return focus to Search.
- Staff mobile workspace: Channels selector, Guides and permission-limited Lookup in one row, clear pearl/lime surfaces, larger conversation area and simpler empty-state guidance. All six channel choices and role boundaries remain.
- Welcome: wait for hero load, crossfade to the approved gold emblem, then reveal the workspace. Skip, Replay, image-failure timeout and static reduced-motion alternative. No new business mutations or live customer test data.
- The existing hero artwork and owner image-fit/height settings are preserved. A generated concept is not a replacement garment/model asset.

Delivery: GitHub isolated release verification must pass before production merge/activation. Staff code is served by the Cloudflare Worker. Public customer pages require the code update ZIP to be extracted over the existing Namecheap public_html; it preserves existing photographs.
